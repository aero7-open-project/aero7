# Aero7 Beta 2

Aero7 Beta 2 is the second public test release of the independent Arch
Linux-based Aero7 operating system.

## Highlights

- dedicated Aero7 Desktop Wayland session with Plasma fallback sessions;
- Windows-inspired taskbar, Start menu, desktop, login and lock experience;
- Dolphin-based Aero7 File Explorer with Libraries and Computer views;
- 45-item Control Panel and Linux-backed system settings;
- searchable **Turn Aero7 features on or off** manager;
- Desktop Gadgets and the optional Programs Center Beta;
- Windows-style `Meta+Shift+S` region capture with automatic PNG save,
  clipboard image data and an actionable notification;
- separate recommended offline and smaller online installation paths.

## Installation media

**No ISO files are attached to this GitHub release.** Download the official
online or offline installation image and its SHA-256 checksum from the
[Aero7 website](https://aero7.miku-dayo.com/). The offline ISO is recommended
because it carries the base installation package set and does not require an
internet connection during setup.

Never install an image from an unofficial mirror or one whose complete
SHA-256 checksum does not match the value shown by the Aero7 website.

## Important

Beta software can contain serious bugs. Back up important files, disconnect
unrelated drives and verify the selected target disk before installation.
Aero7 Beta 2 targets x86-64 UEFI systems; Secure Boot, legacy BIOS, full-disk
encryption and unrestricted manual partitioning are not supported.
